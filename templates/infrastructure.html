Passwordless Sudo Requirement

Infrastructure installer buttons use sudo -n. This prevents the web request from hanging on an invisible password prompt. For these buttons to work, the Linux user running this panel must be allowed to run the needed sudo commands without an interactive password.

Run the project setup helper from an SSH session or local terminal:

chmod +x setup.sh
./setup.sh

It writes a restricted sudoers file for only the optional installer commands this page needs:

/etc/sudoers.d/dune-web-admin

Then verify:

sudo -l
sudo -n apt update
Do not use NOPASSWD: ALL for this panel. It grants far more host access than Easy Dune Admin needs.
